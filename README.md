# Escaner-de-tickets
Aplicación que permite procesar tickets mediante OCR.

# Requisitos:

Python 3.10 o superior,
pip instalado

# Instalación de dependencias
Ejecutar en la carpeta del proyecto:

pip install -r requirements.txt

Si aparece algún error relacionado con Flask, actualizarlo con:

pip install --upgrade Flask

# Ejecutar la aplicación
python app.py
